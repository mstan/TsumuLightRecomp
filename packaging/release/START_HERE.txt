Tsumu Light Recompiled @VERSION@

Run Tsumu_Light_Recompiled.exe (Windows), or the AppImage on Linux.
Choose your own Tsumu Light (Japan, SLPS-02253) disc in the launcher.
The default relative path is tsumu/Tsumu Light (Japan).cue; keep its BIN beside it.
Bundled OpenBIOS is selected automatically; no retail BIOS is required.

Internal Resolution defaults ON at 4x. Use Mods to choose Native (1x) through
32x; saved choices persist. Disabling the mod uses native resolution.
Adaptive View, Stable World Textures and English localization remain available
with their existing defaults. The stage/battery HUD anchors top left, and the
complete block preview anchors top right. Your authored input bindings remain.
Native memory cards use the saves directory; preserve your existing saves/settings.

Interpolation is unavailable. CD Speed and Fast Loading packages are not shipped.
No title-specific loading speedup or new per-title performance gain is claimed.
